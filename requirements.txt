Для запуска решения необходимо подключить следующие библиотеки Python:
- Tkinter - для работы с графическим интерфейсом
- Sqlite3 - для работы с базой данных
- Datatime - для работы с объектами даты

Данные библиотеки являются базовыми. sqlite3 библиотека входит в стандартную библиотеку Python (начиная с версии 2.5), при более поздней версии, необходимо ее установить.
