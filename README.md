# Проект по питону. "Умный планер"
## Описание
Создание приложения, которое позволяет создавать свое учебное расписание, вносить задание по каждому предмету, а так же сортировать задания по важности. 

Главная задача данного приложения : выдавать на каждый день список заданий, которые необходимо выполнить, при этом программа должна сортировать задания по степени важности (каждому заданию пользотель самостоятельно даёт оценку по важности от 1 до 3 на этапе внесения д/з) 

## Реализуемый функционал

### Принцип работы 
Вы открываете приложение. На стартовом экране перед вами будут две кнопки: «Получить» и «Внести». 

- <b>Получить</b>: Нажав на эту кнопку, вы получите список заданий на ближайший учебный день, отсортированный по степени важности. Важно! Задания будут выводиться в порядке убывания их приоритета, что позволяет сосредоточиться на самых значимых делах в первую очередь. Так же предполагается, что программа будет дополнительно выводить чуть ниже весь список заданий с их дедлайнами, задания сортируются по дате (начиная от ближайшей).(данная поправка добавляется в силу того, что некоторые задания требуют для их выполнения больше 1 дня.)

- <b>Внести</b>: Эта функция позволит добавить новые задания в ваш список.  Выберите название предмета, выберите дату, в которое это задание должно быть выполнено (программа должна выдать даты, лежащие в промежутке 1 месяца от сегодняшней даты), впишите домашнее задание и оцените его важность по шкале от 1 до 3. Программа сама отсортирует и добавит эти задания в общий список.


- <b> Примечание</b>: поскольку данное приложение представляет собой планер, предполагается, что пользователь может помимо записи основного д/з добавлять себе задачи самостоятельно, например: выбор предмета -> выбор даты -> "прочитать первую главу лекции" -> важность. 
Также программа должна синхронизироваться с датой и временем, установленными на устройстве. 

## Архитектура

<b>Библиотеки</b>:

1. Datatime - для работы с объектами даты/времени
2. Sqlite - для работы с базой данных, в которой будут храниться задания.
3. Tkinter - для работы с графическим интерфейсом
* библиотека Sqlite была выбрана, тк является базовой библиотекой Python и позволяет удобно отображать данные в формате таблицы.

<b>Классы</b>: Schedule (расписание), Task (Задание), Application (Приложение)

<b>Атрибуты</b>: 

Для класса Task :
1. subject (str): Название предмета.
2. description (str): Описание задания.
3. due_date (datetime): Дата выполнения задания.
4. importance (int): Важность задания (1 - низкая, 2 - средняя, 3 - высокая).

Для класса Schedule:
1. tasks (list): Список заданий (объекты класса Task).
2. tasks.append(task): Для добавления заданий в список заданий

Для класса Application:
1. schedule (Schedule): Объект класса Schedule, содержащий задачи.
2. title: Заголовок GUI
3. geometry: Используется для установки размеров и положения окна приложения
4. create_widgets: Используется для создания виджетов приложения
5. create_database: Используется для создания базы данных, где будут храниться задания
6. load_tasks_from_db: Используется для загрузки заданий из базы данных при запуске приложения
7. save_task_to_db: Используется для сохранения заданий в базу данных

<b>Функции</b>: 
- функция инициализации (def __init__) 
- функция добавления объектов в список (def add_task)
- функция создания базы данных (def create_database)
- функция создания виджетов (def create_widgets)
- функция сортировки заданий по времени выполнения и важности (def get_sorted_task)
- функция сохранения задания в базу данных (def save_task_to_db)
- функция загрузки заданий из базы данных (def load_tasks_from_db)
- функция отображения заданий (def show_tasks)
- функция очистки полей для ввода после сохранения задания для избежания накладок текста при последующем введении задания (def clear_entries)
- функция закрытия соединения с базой данных (def on_closing)
