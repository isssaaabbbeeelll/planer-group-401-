<h1 alighn= "center"> Проект по питону. "Умный планер" 
</h2>Описание: Создание приложения, которое позволяет вносить свое учебное расписание, домашнее задание по каждому предмету, а так же сортировать задания по важности. Главная задача данного приложения : выдавать на каждый день список заданий, которые необходимо выполнить, при этом программа должна сортировать задания по степени важности (каждому заданию пользотель самостоятельно даёт оценку по важности от 1 до 3 на этапе внесения д/з) 
</p> Принцип работы:   открываете приложение. На стартовом экране перед вами будут две кнопки: «Получить» и «Внести». 

</p>- Получить: Нажав на эту кнопку, вы получите список заданий на ближайший учебный день, отсортированный по степени важности. Важно! Задания будут выводиться в порядке убывания их приоритета, что позволяет сосредоточиться на самых значимых делах в первую очередь.

</p>- Внести: Эта функция позволит добавить новые задания в ваш список. Выберите название предмета, впишите домашнее задание и оцените его важность по шкале от 1 до 3. Программа сама отсортирует и добавит эти задания в общий список, основываясь на вашем расписании и сроках.
