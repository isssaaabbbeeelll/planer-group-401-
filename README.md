<h1 alighn= "center"> Проект по питону. "Умный планер" 
Создание приложения, которое позволяет вносить свое учебное расписание, домашнее задание по каждому предмету, а так же сортировать задания по важности. Главная задача данного приложения : выдавать на каждый день список заданий, которые необходимо выполнить, при этом программа должна сортировать задания по степени важности (каждому заданию пользотель самостоятельно даёт оценку по важности от 1 до 3 на этапе внесения д/з) </h2>
