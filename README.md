<h1 alighn= "center"> Проект по питону. "Умный планер" 
</h2>Описание: Создание приложения, которое позволяет вносить свое учебное расписание,задание по каждому предмету, а так же сортировать задания по важности. Главная задача данного приложения : выдавать на каждый день список заданий, которые необходимо выполнить, при этом программа должна сортировать задания по степени важности (каждому заданию пользотель самостоятельно даёт оценку по важности от 1 до 3 на этапе внесения д/з) 

<h3 alighn = "center"> Реализуемый функционал

</h4>Принцип работы: Вы открываете приложение. На стартовом экране перед вами будут две кнопки: «Получить» и «Внести». 

</p>Получить: Нажав на эту кнопку, вы получите список заданий на ближайший учебный день, отсортированный по степени важности. Важно! Задания будут выводиться в порядке убывания их приоритета, что позволяет сосредоточиться на самых значимых делах в первую очередь. Так же предполагается, что программа будет дополнительно выводить чуть ниже весь список заданий с их дедлайнами, задания сортируются по дате (начиная от ближайшей).(данная поправка добавляется в силу того, что некоторые задания требуют для их выполнения больше 1 дня.)

</p>Внести: Эта функция позволит добавить новые задания в ваш список.  Выберите название предмета, выберите дату, в которое это задание должно быть выполнено (программа должна выдать даты, лежащие в промежутке 1 месяца от сегодняшней даты), впишите домашнее задание и оцените его важность по шкале от 1 до 3. Программа сама отсортирует и добавит эти задания в общий список, основываясь на вашем расписании. 


</p>Примечание: поскольку данное приложение представляет собой планер, предполагается, что пользователь может помимо записи основного д/з добавлять себе задачи самостоятельно, например: выбор предмета -> выбор даты -> "прочитать первую главу лекции" -> важность. 
Также программа должна синхронизироваться с датой и временем, установленными на устройстве. 

<h3 alighn= "center"> Архитектура </h3> 

</p>Классы: Schedule (расписание), Task (Задание), Application (Приложение)
</p>Атрибуты: 
   </p> Для класса Task :
   </p> - subject (str): Название предмета.
   </p> - description (str): Описание задания.
   </p> - due_date (datetime): Дата выполнения задания.
   </p> - importance (int): Важность задания (1 - низкая, 2 - средняя, 3 - высокая).
   </p> Для класса Schedule:
   </p> - tasks (list): Список заданий (объекты класса Task).
   </p> Для класса Application:
   </p> - schedule (Schedule): Объект класса Schedule, содержащий задачи.
   
   </p> - Функции : функция инициализации, функция добавления объектов в список, функция создания новых объектов, функция возврата (списка, объекта), функция отображения задач, иначе: выводит соответсвующее сообщение. (в случае. если задачи отсутсвуют).
